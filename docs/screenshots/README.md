# Project Screenshots — add yours here before zipping

The submission package expects project screenshots (see assignment instructions).
Capture these 6 screenshots from the **live game** (open `index.html` or the
GitHub Pages link) and save them in this folder with exactly these names:

| File name | What to capture |
|---|---|
| `01-menu.png` | The main menu screen (title, Start button, high scores) |
| `02-gameplay.png` | Mid-flight gameplay — drone + HUD visible |
| `03-collision.png` | A collision effect (sparks / shake / toast text) |
| `04-storm.png` | Flying through a storm cell / rain on screen |
| `05-day-night.png` | Night-time (drone headlight + darker world) |
| `06-gameover.png` | End screen with score, distance, efficiency grade |

How to take them: in the game, press **F12** to open DevTools, use the
**F12 → Command Menu → "Capture screenshot"** (Ctrl+Shift+P → type
"screenshot") which captures the canvas exactly, or just use **Windows
Snipping Tool** (Win+Shift+S).

> ⚠️ The two report files use an embedded emoji. Alternatively, lay these
> screenshots into the Word report (African Context Report) as figures — 2 or
> 3 gameplay shots make the report look much stronger.
